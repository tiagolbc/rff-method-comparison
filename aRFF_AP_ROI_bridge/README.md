# aRFF-AP ROI bridge

This folder retains the supplied aRFF-AP source files and dependencies together with separate ROI-adapter functions. The adapter replaces automatic fricative localization with externally verified `FricStart` and `FricEnd` boundaries while preserving native pitch estimation, cycle selection, rejection logic, and RFF calculation.

Required citations are listed in the repository root `README.md` and `THIRD_PARTY_NOTICES.md`.
