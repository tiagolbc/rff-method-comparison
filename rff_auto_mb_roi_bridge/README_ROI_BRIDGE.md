# RFF-MB ROI bridge

This folder retains Mark Berardi's original RFF-MB MATLAB implementation and its MIT license, together with a separate ROI-controlled bridge.

The original method uses one `FricLoc` anchor. The bridge uses `FricStart` for offset and `FricEnd` for onset while retaining the native Praat pulse extraction, sliding-window voting, rejection rules, and RFF equations.

Required citation:

Berardi M, Tippit E, Gao Y, DeSouza GN, Dietrich M. Automated Analysis of Relative Fundamental Frequency in Continuous Speech: Development and Comparison of Three Processing Pipelines. *Journal of Voice*. 2025. doi:10.1016/j.jvoice.2025.04.006.
